# NAWI-ReportPro Pitch Deck

This repository contains the print-ready HTML presentation for NAWI-ReportPro (SIH 2026 Grand Finale - PS #26035).

## How to View

1. Navigate to the `presentation` directory.
2. Double-click the `index.html` file to open it in your default web browser (Chrome/Edge/Firefox recommended).

## Features
- 10 professional slides with animations.
- Complete standalone HTML (No dependencies other than Google Fonts via CDN).
- Responsive grid layouts with dark navy and saffron themes.
- SVG generation for India Government branding.

## How to Print / Save as PDF

1. Open `index.html` in Chrome/Edge.
2. Click the **"🖨️ Print / Save as PDF"** button at the top right, or press `Ctrl+P`.
3. In the print dialog settings:
   - **Destination**: Save as PDF
   - **Layout**: Landscape
   - **Paper Size**: A4
   - **Margins**: None (or Default)
   - **Background graphics**: Enabled (Important for dark background and colors!)
4. Click Save.
